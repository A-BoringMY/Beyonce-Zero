# 🚀 Beyond Zero: Pro Edition

![Version](https://img.shields.io/badge/Version-Pro_Edition-00ecff)
![PWA](https://img.shields.io/badge/PWA-Supported-2ecc71)
![Database](https://img.shields.io/badge/Firebase-Realtime_DB-f1c40f)

**Beyond Zero: Pro Edition** ialah sebuah game *incremental/clicker* berasaskan web yang boleh dipasang terus ke skrin telefon pintar anda sebagai Progressive Web App (PWA).

---

## 🎮 Ciri-Ciri Utama (Features)

* **Sistem Rebirth & Power Up:** Kumpul Clicks dan Diamonds untuk tingkatkan *Click Power* serta *Auto Speed*.
* **Automation & Equipment:** Beli *Auto Clicker*, *Diamond Farm*, hingga *Void Blade* untuk mempercepatkan kemajuan anda.
* **Global Leaderboard:** Carta kedudukan pemain secara langsung (*real-time*) disinkronkan mengikut sistem **Season**.
* **Penyimpanan Data Selamat:** Kemajuan game dan markah disimpan secara automatik menggunakan Firebase Realtime Database.
* **PWA Supported:** Boleh dipasang (*install*) terus ke skrin utama telefon Android/iOS seperti aplikasi APK sebenar!

---

## 🛠️ Teknologi Yang Digunakan

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Backend / Database:** Firebase Realtime Database
* **Architecture:** Progressive Web App (PWA) / Service Worker

---

## 📱 Cara Memasang App (PWA)

1. Buka laman web game ini di pelayar Chrome/Safari telefon pintar anda.
2. Tekan menu **3 Titik** di bahagian atas kanan.
3. Pilih **Add to Home screen** (Tambah ke skrin utama) atau **Install App**.
4. Buka game terus dari skrin utama telefon anda!
